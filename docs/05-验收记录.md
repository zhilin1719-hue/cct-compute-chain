## 2. 后端测试覆盖

16 个测试使用临时 SQLite 文件和真实 HTTP 服务，不修改正式本机数据。覆盖：

- 健康检查、公开内容和双语字段。
- 所有后台资源未登录拒绝。
- 密码认证、HttpOnly 会话、退出失效和过期会话。
- Origin、CSRF、请求体格式和体积限制。
- 草稿隔离、发布可见、删除持久化和 seed 不复活。
- 咨询邮箱与 consent 校验、持久保存、跟进状态和统计。
- editor 内容／线索权限，以及对用户、设置、审计的拒绝。
- 最后一位管理员、当前账号停用及账号会话失效保护。
- 密码变化后其他会话失效。
- SQL 注入字符串作为普通数据处理。
- 蜜罐、咨询限流、登录限流。
- 设置公开生效、非法字段不能覆盖。
- 生产 Cookie Secure 属性和审计详情不记录密码。
