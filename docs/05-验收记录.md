## 2. 后端测试覆盖

21 个测试使用临时 SQLite 文件和真实 HTTP 服务，不修改正式本机数据。覆盖：

- 健康检查、公开内容和双语字段。
- 所有后台资源未登录拒绝。
- 密码认证、HttpOnly 会话、退出失效和过期会话。
- Origin、CSRF、请求体格式和体积限制。
- 草稿隔离、发布可见、删除持久化和 seed 不复活。
- 咨询邮箱与 consent 校验、持久保存、跟进状态和统计。
- editor 内容／线索权限，以及对用户、设置、审计的拒绝。
- 最后一位管理员、当前账号停用及账号会话失效保护。
- 密码变化后其他会话失效。
- SQL 注入字符串作为普通数据处理。
- 蜜罐、咨询限流、登录限流。
- 设置公开生效、非法字段不能覆盖。
- 生产 Cookie Secure 属性和审计详情不记录密码。
- v1→v2 数据迁移隔离被编辑过的历史声明，且不会复活已删除的旧内容。
- v2→v3 数据迁移只补充新增业务资料，且不复活已删除内容。
- 市场来源限 HTTPS、日期有效性、证据字段完整性、管理员发布与 OG 元数据唯一性。

## 5. 发布边界

GitHub Pages 永久在线的是公开静态官网；管理后台、API、咨询表单和 SQLite 不在 Pages 上运行。全栈版本已通过本机与隔离数据库验收，需在具备持久存储、HTTPS 和密钥管理的服务器上另行部署。未执行生产流量压测、第三方渗透测试或企业合规审计。

隐私政策、条款、集团主体、品牌资产、真实案例和合作伙伴在公开发布前需要权利人核准。算力图是概念可视化，当前系统没有接入 GPU 实时监控、支付、链上交易、外部 CRM 或模型推理。
