# CCT 算链集团官网 · 产品与功能颗粒度

版本：1.0；交付性质：独立可运行的官网与内容运营系统。此文档描述当前开发范围；实测结果以 `05-验收记录.md` 为准。

## 1. 产品目标与内容边界

主要访客为企业客户、行业合作伙伴与开发者。第一目标是清楚理解 CCT 的算力、AI 模型、智能体与产业方案方向，第二目标是提交可跟进的合作需求。集团定位源于历史规划，尚未获得企业主体、真实客户、合作授权、业务上线证明、备案或品牌规范。本版不编造客户、合作伙伴、交易额、GPU 在线数量、融资进度或可兑现的投资收益。

首发内容为可编辑的官网文案草案。算力拓扑图为概念可视化，不连接 GPU 节点，也不表示实际部署分布。本系统管理网站与咨询业务，不充当 GPU 调度、模型推理、支付结算或代币交易系统。

## 2. 用户与权限

| 角色 | 可访问 | 可执行 | 禁止事项 |
|---|---|---|---|
| 公众访客 | 所有公开页面、已发布内容 | 搜索／筛选内容、切换语言、提交合作需求 | 读取草稿、读取线索、调用后台接口 |
| 内容编辑 editor | 后台工作台、内容、线索、本人账号 | 内容增改删、发布、线索跟进、本人改密 | 站点全局设置、账号管理 |
| 管理员 admin | 全部后台功能 | 编辑全部站点内容、管理账号、角色和启停状态 | 删除最后有效管理员、自行停用造成锁定 |

权限在后端执行，前端隐藏菜单只用于减少操作干扰。

## 3. 公众网站：逐页功能

| 页面／地址 | 页面组成 | 可执行操作 | 数据来源与状态 |
|---|---|---|---|
| 首页 `/` | 品牌导航、大标题、轨道网络图、业务能力、行业方案、生态、洞察、页脚 | 查看业务、查看方案、进入合作咨询 | 全局设置＋已发布内容；图形为概念展示 |
| 业务能力 `/services` | 能力列表、分类、摘要、详情入口 | 按分类探索、查看服务详情 | type=service 的已发布内容 |
| 行业方案 `/solutions` | 行业列表、方案卡片、合作入口 | 筛选行业、查看方案 | type=solution 的已发布内容 |
| 生态合作 `/ecosystem` | 合作伙伴类型、协作流程、关系图 | 选择合作方向，带入咨询需求 | 静态生态结构＋咨询表单 |
| 前沿洞察 `/insights` | 搜索、文章分类、内容列表 | 按关键词或分类找文章、阅读详情 | type=insight 的已发布内容 |
| 集团介绍 `/about` | 品牌愿景、价值主张、业务方向 | 查看能力、进入咨询 | 网站内容草案；无虚构里程碑 |
| 内容详情 `/content/:slug` | 分类、标题、摘要、正文、返回／咨询入口 | 阅读、返回列表、提交需求 | 根据 slug 查找已发布内容；未发布显示未找到 |
| 合作咨询 `/contact` | 联系人、邮箱、公司、方向、需求、同意项 | 校验、提交、确认结果、错误重试 | POST 公共接口；成功写入 leads 表 |
| 隐私说明 `/privacy` | 收集信息、用途、保存与联系说明 | 从表单进入查阅 | 网站文案草案，主体和实际联系邮箱待核准 |
| 使用条款 `/terms` | 内容使用边界与信息说明 | 查阅条款 | 网站文案草案 |
| 无效地址 | 独立 404 页面 | 返回首页 | 不显示假内容 |

### 3.1 全站交互

- 中文／英文切换：导航、CTA、表单、状态文案及双语内容字段同步；语言是设备偏好，业务数据仍来自服务器。
- 当前导航状态：所在页面可辨认；移动端导航可展开、关闭和跳转。
- 键盘访问：有跳到正文链接、可见焦点、真实按钮和表单标签。
- 动效：图形限制像素比，响应窗口变化；系统启用减少动态效果时停止或弱化动画。
- 数据加载：加载状态、失败状态、重试入口与空列表；接口失败不冒充成功。
- 响应式：桌面、平板及 390 像素手机布局；表单单列、卡片换行、长文本可断行。

### 3.2 咨询表单字段

| 字段 | 类型 | 规则与用途 |
|---|---|---|
| name | 文本 | 必填；联系人姓名 |
| email | 邮箱 | 必填；服务器校验邮箱格式 |
| company | 文本 | 公司或组织，限制长度 |
| interest | 枚举／文本方向 | 算力、AI、智能体、产业应用、生态合作等需求方向 |
| message | 多行文本 | 必填需求描述；服务器限制长度 |
| consent | 布尔 | 必须明确勾选；不默认代替用户同意 |
| website | 隐藏蜜罐 | 拦截基础脚本垃圾提交 |

提交时禁用重复操作；失败保留填写内容；成功显示已收到。实际系统不自动发邮件，运营人员在后台查看并跟进。

## 4. 管理后台：功能拆解

### 4.1 登录与本人账号

1. 邮箱与密码登录，校验失败显示通用错误。
2. 服务端生成会话，浏览器仅保存 HttpOnly Cookie。
3. 刷新时恢复有效会话；过期时回到登录。
4. 退出登录使当前会话失效。
5. 本人修改密码需验证当前密码，新密码至少 12 位。
6. 密码变化后其他会话失效，降低遗留登录风险。
7. 首次初始化生成独立随机密码；不内置公开通用密码。

### 4.2 工作台 `/admin`

1. 内容总数、已发布数量、线索总数、待跟进数量均来自数据库。
2. 最近咨询列表可帮助运营确定处理次序。
3. 线索时间分布图由实际记录计算。
4. 新数据库允许零线索；不放置虚构客户来填满工作台。

### 4.3 内容管理 `/admin/content`

| 功能 | 颗粒度 |
|---|---|
| 列表 | 标题、类型、分类、状态、更新时间、操作入口 |
| 查找 | 关键词查找及类型／状态筛选 |
| 新建 | 选择 service／solution／insight，创建新内容 |
| 地址 | 唯一 slug；冲突返回可理解错误 |
| 双语 | 中文标题、英文标题、中文摘要、英文摘要、中文正文、英文正文 |
| 分类 | 运营可填写分类标签，用于前台展示／筛选 |
| 推荐 | featured 开关用于首页推荐 |
| 草稿 | 保存为 draft；公共接口不返回草稿 |
| 预览 | 查看编辑结果；不修改发布状态 |
| 发布 | 切换为 published 后公共接口可读取 |
| 下线 | 改回 draft，公共网站无法读取 |
| 删除 | 二次确认后删除；记录操作审计；恢复依赖备份 |

正文使用纯文本段落，避免任意 HTML 和脚本进入网站。当前没有图片上传、多人编辑锁、历史版本回滚、定时发布或审批流。

### 4.4 线索管理 `/admin/leads`

1. 列出公众网站提交的真实咨询。
2. 按关键词、跟进状态筛选。
3. 展开详情查看姓名、邮箱、公司、合作方向、原始描述和提交时间。
4. 状态流：新线索 new → 已联系 contacted → 有效商机 qualified → 已关闭 closed；允许运营按真实情况修改。
5. 编辑内部跟进备注，保存到数据库。
6. 修改行为写入操作记录。
7. 不自动发送外部消息，不把线索数量当成已成交业绩。

### 4.5 站点设置 `/admin/settings`

管理员可修改品牌名称、中英文首页主标题、中英文首页介绍和联系邮箱。保存后刷新公开页面可读取新设置。邮箱只是站点联系信息，不代表已配置收件服务。

### 4.6 账号管理 `/admin/users`

1. 查看账号姓名、邮箱、角色和状态。
2. 新建管理员或编辑账号，要求独立密码。
3. 修改姓名、角色和启停状态。
4. 重置账号密码。
5. 邮箱唯一；重复创建返回冲突。
6. 防止管理员自行停用／降权导致失去管理入口，保护最后有效管理员。
7. 密码散列和会话令牌不在账号 API 中返回。

### 4.7 操作记录 `/admin/audit`

查看操作人、时间、动作、对象与详情，覆盖内容、线索、站点设置和账号变化。此为应用内部审计，数据库管理员仍能修改底层数据；并非不可篡改存证服务。

## 5. 界面系统

| 维度 | 规范 |
|---|---|
| 品牌基调 | 深墨绿黑、浅灰白、浅荧光绿强调；避免大量霓虹发光和不可读细字 |
| 主视觉 | 自绘算力轨道与节点关系，概念展示；无第三方网络请求 |
| 排版 | 大标题与清晰中文正文，英文等宽标签作为辅助 |
| 导航 | 桌面水平导航、移动端菜单；后台独立侧栏 |
| 按钮 | 明确区分主行动、次行动、危险操作和禁用状态 |
| 内容密度 | 官网留白与分段阅读；后台紧凑且可扫描 |
| 反馈 | 表单字段校验、操作中状态、成功提示、错误提示与可恢复入口 |
| 安全交互 | 删除确认、密码不回显、编辑权限限制、过期会话提示 |

## 6. 当前范围以外的独立系统

GPU 实时库存与调度、模型推理 API、真实智能体执行、付款与开票、第三方 CRM、外部邮件／短信、资源上传、招聘管理、MFA／企业 SSO、Token／链上交易、真实客户案例验证，均不包含在本次网站系统中。已有官网提供它们的介绍和咨询入口；后续接入需要相应真实服务、权限、数据与独立验收。
