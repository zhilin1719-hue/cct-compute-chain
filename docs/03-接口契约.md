# CCT API 接口契约

接口基路径 `/api`。请求和响应均使用 JSON。错误形态 `{ "error": "可理解的错误说明" }`；字段校验可能包含字段详情。时间使用 ISO 日期字符串。精确状态码和输入约束由 `server/index.mjs`、`server/db.mjs` 和行为测试定义。

## 通用规则

- 浏览器同源调用，不向第三方域名发送管理员凭据。
- POST、PUT、PATCH、DELETE 验证 Origin。无来源的自定义 HTTP 客户端需显式发送合法 Origin。
- 管理写请求还需 Cookie 会话和 `X-CSRF-Token`；登录成功和 `/auth/me` 返回 CSRF token。
- 身份缺失返回 401；角色不允许返回 403；非法输入返回 400；不存在返回 404；重复约束通常为 409；限流为 429。
- 内容和线索 ID 为服务端生成；不要依赖示例 ID。

## 公共接口

| 方法／路径 | 入参 | 响应 | 行为 |
|---|---|---|---|
| GET `/health` | 无 | 服务健康状态 | 用于存活探测 |
| GET `/public/bootstrap` | 无 | `{settings,content}` | 仅返回公开设置、已发布内容 |
| GET `/public/content/:slug` | slug | {item} | 草稿／不存在均不公开 |
| POST `/public/leads` | name,email,company,interest,message,consent,website | `{id,message}` | 验证后持久保存 |

咨询请求示例（仅说明结构；不要把示例当作真实客户）：

```json
{
  "name": "联系人姓名",
  "email": "contact@example.com",
  "company": "企业名称",
  "interest": "企业智能体",
  "message": "请说明实际业务场景、现有系统与希望改善的流程。",
  "consent": true,
  "website": ""
}
```

## 身份接口

| 方法／路径 | 入参 | 返回与影响 |
|---|---|---|
| POST `/auth/login` | email,password | 用户最小字段＋csrfToken；Set-Cookie |
| GET `/auth/me` | Cookie | 当前用户＋csrfToken |
| POST `/auth/logout` | Cookie＋CSRF | 当前会话失效 |
| POST `/auth/password` | currentPassword,newPassword | 本人密码更新，其他会话失效 |

## 内容接口（管理员／编辑）

| 方法／路径 | 入参 | 响应 |
|---|---|---|
| GET `/admin/content` | 无 | `{items:[...]}` |
| POST `/admin/content` | 内容字段 | `{item:{...}}` |
| PUT `/admin/content/:id` | 内容字段 | `{item:{...}}` |
| DELETE `/admin/content/:id` | id | 成功确认 |

内容字段：`type`（service/solution/insight）、`slug`、`title`、`titleEn`、`summary`、`summaryEn`、`body`、`bodyEn`、`category`、`status`（draft/published）、`featured`。字符串按后端约束限定长度。新建、编辑和删除均记录操作。

## 线索与工作台（管理员／编辑；审计仅管理员）

| 方法／路径 | 入参 | 响应／行为 |
|---|---|---|
| GET `/admin/stats` | 无 | 内容统计、线索统计、最近线索、按日分布 |
| GET `/admin/leads` | 可选 q,status | `{items:[...]}` |
| PATCH `/admin/leads/:id` | status,notes | 更新跟进信息 |
| GET `/admin/audit` | 无 | `{items:[...]}` 操作记录 |

线索状态：`new`、`contacted`、`qualified`、`closed`。状态是跟进标记，不自动发送邮件、不触发支付或合同。

## 管理员专属

| 方法／路径 | 入参 | 行为 |
|---|---|---|
| GET `/admin/settings` | 无 | `{settings}` |
| PUT `/admin/settings` | 设置字段 | 保存全站设置 |
| GET `/admin/users` | 无 | `{items}`；不返回密码散列 |
| POST `/admin/users` | name,email,password,role | 创建账号；邮箱唯一 |
| PATCH `/admin/users/:id` | name?,role?,active?,password? | 改名、角色、启停、重置密码 |

设置字段：brandName、heroTitle、heroTitleEn、heroSubtitle、heroSubtitleEn、contactEmail。保存全量表单可避免遗漏；API 对受支持字段验证后更新。

## 数据隔离验收

1. 未登录请求 `/admin/content` 返回 401。
2. 编辑账号写 `/admin/settings` 或管理用户返回 403。
3. 有效 Cookie 缺失 CSRF token 的管理写请求被拒绝。
4. 非允许来源的写请求被拒绝。
5. 草稿既不出现在 bootstrap，也不能通过猜 slug 获取。
6. SQL 特殊字符不改变查询结构。
7. 页面中内容文本不执行脚本。
