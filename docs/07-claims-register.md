# CCT 官网主张与证据台账

更新时间：2026-09-25

本台账用于隔离两份宣传册中的公司自述、规划目标、外部行业数据和未经核验的硬指标。宣传册是内容输入，不是独立证据。任何公开硬数字必须能追溯到责任主体、原始证据、适用范围、发布日期和有效期。

## 发布规则

| 证据状态 | 含义 | 是否允许公开 |
| --- | --- | --- |
| `official` | 监管机构、标准机构、公司投资者关系或其他一手公开来源 | 可作为外部市场数据公开，必须显示来源与日期 |
| `internal` | CCT 的方法、能力说明或内部材料 | 可描述能力和方法，不得自动转化为已交付业绩 |
| `external` | 外部二手分析 | 仅作研究线索，不作为官网硬数字的唯一来源 |
| `unverified` | 无证书、合同、监控、财务、验收或授权证明 | 禁止发布；后台完整性校验会拒绝，且只有管理员可执行发布 |

## 责任与复核

每项从 `unverified` 转为可公开状态前，需要在本台账或集团证据库中填写证据所有人、审核人、公开范围、来源 URL 或附件、有效期和复核日期。当前后台校验来源字段完整性、HTTPS、日期、证据等级和管理员发布权限，并在审计日志保留证据字段变更；它不替代法务、财务、合规或业务负责人对证据真实性的专业审核。涉及金融、医疗、教育、未成年人、飞行或高影响人事决策时，还需要相应专业责任人完成复核。
