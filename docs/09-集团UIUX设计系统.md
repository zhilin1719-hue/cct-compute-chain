# CCT Photon · 集团 UI/UX 设计系统

版本：2026-09-28。适用范围：集团官网、十五大业务探索、产品与行业方案、内容详情、合作入口、运营管理后台。

## 设计目标

把 CCT 的算力、数据、智能体与产业协同关系转化为可浏览、可查找、可继续行动的集团网站。保留集团材料中的八层能力结构，并将业务地图扩展为十五个方向；新增方向按规划、官方市场证据和项目边界表达，不写成已交付规模。

主视觉采用自主生成的光学晶体与蓝色光路概念作品；WebP 资产约 202 KiB，固定尺寸避免加载位移，首屏优先加载，不依赖第三方图片服务。它是品牌概念图，不代表真实设备。

## 访问者任务流程

1. **集团认知**：首屏品牌定位 → 集团业务 → 选择业务方向 → 关联能力/方案。主视觉旁保留概念说明。
2. **目标导向探索**：提升效率 / 构建 AI 基础设施 / 寻找增长 → 业务目标面板 → 相关产品详情。支持方向键、Home、End 切换。
3. **直接查找**：导航搜索按钮或 Ctrl/Cmd + K → 输入关键词 → 查看结果 → 打开详情。无结果时可清空；Esc 关闭并恢复触发位置焦点。
4. **产品筛选**：分类与关键词 → 实时结果数量 → 详情。零结果时保留重置筛选操作，避免死路。
5. **阅读与判断**：面包屑/返回集合 → 摘要 → 正文 → 证据标签、来源日期和官方来源 → 下一步合作入口。
6. **合作咨询**：本机动态系统支持表单校验、发送中、失败重试与成功确认；GitHub Pages 公开版本不提供不可用的填写表单。

## 运营工作台流程

- 概览：内容数、发布数、咨询数与待处理数全部来自 API；统计卡进入对应管理列表。
- 内容编辑：基本信息 → 来源与核验 → 中文/英文正文 → 草稿或管理员发布。
- 合作咨询：列表筛选 → 需求详情 → 跟进状态；保留当前数据库与权限约束。
- 账号与权限：正常、停用和角色状态清晰展示，危险操作保留确认与服务端校验。
- 手机导航：打开聚焦、Tab 循环、Esc 关闭、返回触发按钮；切回桌面时解除滚动锁。
- 表格、抽屉和表单使用统一的字号、边界、间距与状态样式。

## 状态与可访问性约束

| 状态/操作 | 必须提供的反馈 |
| --- | --- |
| 正常/悬停/当前/键盘焦点 | 颜色、边界与清晰焦点环共同区分 |
| 加载 | 结构化占位或带文本的状态提示 |
| 空结果 | 说明与清空/重置操作 |
| 网络失败 | 错误说明与重试按钮 |
| 发送/保存中 | 禁止重复提交并显示忙碌文本 |
| 表单必填/错误 | 标签、约束、错误说明；不只依赖颜色 |
| 对话框 | 语义标题、modal 行为、Esc、恢复焦点 |
| 业务规划阶段 | 标签文字和说明；不单靠状态颜色 |
| 语言 | 中文与英文独立配置，不覆盖管理员自定义标题 |
| 响应式 | 检查页面总宽与关键容器实际边界，避免用裁切掩盖溢出 |

本次视觉检查与自动化回归不等于完整 WCAG 认证。辅助技术实机测试、全量业务文案确认及正式数据采集配置仍需按具体上线环境完成。

## Photon 色彩与细节规范

- 官网底色 #050914，分区 #080e1c，卡片 #0c1528 / #101d34，边界 #20314d。
- 主行动蓝 #2869e8，辅助高光 #65dfff，仅用于局部识别与可见焦点。冷白 #edf4ff、次级正文 #a6b5cf。
- 官网采用深色原生控件主题；后台采用深蓝导航与冷白工作区，危险、成功与待处理状态保留独立语义。
- 首屏使用真实图像资产，晶体完整显示，固定宽高比，移动端独立比例；无持续扫描光束。
- 搜索从移动导航快捷键打开后，关闭时若原焦点已隐藏，恢复到可见搜索按钮。
- 业务地图仅展示当前公开内容集合中的关联入口，下架内容不再产生失效链接。
- 视觉参考的官方页面： https://x.ai/ 、https://linear.app/ 、https://www.nvidia.com/en-us/ai/ 。这些是信息架构参考，不是 CCT 客户、合作或能力背书。
